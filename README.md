# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

印刷员可设置每日禁投钟点范围（服务器钟点，闭区间，可跨午夜）。服务器时刻落在区间内时，投递一律以 409 退回并写入禁投流水，挪开窗后才允许入队。只读账号可看钟点配置与流水，不能改配置。

```bash
cd projects/15-print-register-review

```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. 菜单进入「班次禁投」：可见钟点配置、服务器当前时刻与是否禁投、禁投流水。printer 把禁投窗改成盖住此刻（起止取当前钟点、止取后一分钟），回队列送复核应报错退回，回到班次禁投页能看到新增流水；再把禁投窗挪开此刻，送插页-02 应收下并入队。
5. 用 checker 登录进班次禁投页，可看配置和流水，但配置框只读、无保存按钮，直接调接口 `PUT /api/ban-window` 返回 403。
