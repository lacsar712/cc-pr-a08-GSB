# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

印刷员可设定每日禁投钟点窗（闭区间，支持跨午夜）。服务器时刻落在窗内的投递一律退回，提示移出该钟点窗后才允许入队，每次命中都写入禁投流水。只读账号能看钟点配置与流水，但改不了配置。顶部菜单的“班次禁投”页可看钟点配置、当前是否禁投以及禁投流水。

```bash
cd projects/15-print-register-review

```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. printer 打开“班次禁投”页，把禁投钟点改成盖住服务器当前时刻；回印张复核页送一条插页，应被退回并提示处于禁投钟点窗，禁投流水多出一条。
5. 回班次禁投页把钟点挪开（或停用禁投），再送同一插页，应正常收下，随后变成套准。
6. checker 打开“班次禁投”页能看钟点配置与流水，但没有保存按钮；直接调 `PUT /api/forbidden-window` 返回 403。
